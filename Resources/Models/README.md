
This directory contains model files used by ZeroSpades.

Some files are replaced with placeholder model files due to license restrictions.
If you find suitable GPL-compatible model files, please add them to the source tree.

As a side note: assets of a commercial game are not guaranteed to be GPL-compatible
even if the source code of the game is licensed under GPL. The examples include
ZeroSpades and Quake 3: Arena.

Placeholder model files are suffixed with `.weak` so that files from the non-free
paks take precedence.
